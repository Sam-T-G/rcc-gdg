# Guest speaker

## Purpose

A guest speaker event brings a Googler, an alum, or an industry engineer to campus. The ASRCC FY 2026-27 request budgets this as "Google Guest Speakers & Workshops" at $2,000 (transportation 500, lodging 500, meals 600, marketing and swag 200, technology 100, supplies 100) with a target of 50+ attendees in BLCIS. That line sets the bar: a speaker event should draw more than a regular meeting and should be funded, acknowledged, and reported like one.

## When

Once or twice a semester, in a slot with enough lead time to book a larger room and promote for at least three weeks. Speakers from outside Riverside need six weeks or more to arrange travel.

## Owner

Event lead. The advisor must attend (RCC requires the advisor at all club events) and submits the room and event paperwork.

## T-minus checklist

### T-6 weeks

- [ ] Choose the speaker and topic. Write one sentence on why this speaker for this audience.
- [ ] Invite in writing. Ask for: talk title, a two-sentence abstract, a short bio, tech needs, whether they consent to being recorded and streamed on Bevy, and travel needs.
- [ ] Decide funding: club trust account, ASRCC allocation, or none. If ASRCC money is involved, read [asrcc-funding.md](../02-operations/asrcc-funding.md) and [reimbursements.md](../02-operations/reimbursements.md) before promising anything. Do not promise a speaker fee; ASRCC does not fund personnel.
- [ ] Advisor submits 25Live for the room (students cannot). If expecting 50+, ask for a room larger than the weekly one and include tables and chairs in the original request ([room-booking.md](../02-operations/room-booking.md)).
- [ ] Run `scripts/new-event.sh` and fill in [templates/event-plan.md](../../templates/event-plan.md) with the budget lines.

### T-4 weeks

- [ ] Advisor files the Student Activities Event Form with the printed 25Live confirmation. If food is served, file the Food Authorization form ([event-checklist.md](../02-operations/event-checklist.md)).
- [ ] Publish the Bevy event ([bevy-event-publishing.md](bevy-event-publishing.md)) with the speaker's title and bio. Every RSVP consents to recording under the GDG Participation Terms; tell the speaker that too.
- [ ] Book travel and lodging only after the funding source is confirmed in writing. Keep every receipt.

### T-3 weeks

- [ ] Flyer and announcement ([templates/announcement.md](../../templates/announcement.md)). Post to Discord and Instagram. Ask faculty to announce in class.
- [ ] If ASRCC funds it, the flyer and the opening remarks must acknowledge ASRCC.
- [ ] Get the speaker's slides or at least the format (their laptop, ours, or a link). Confirm the projector input.

### T-1 week

- [ ] Reminder post. Check RSVPs on Bevy against room capacity.
- [ ] Confirm arrival time, parking, and where to meet the speaker. Send them the room name (BLCIS, room per the booking) and a campus map link.
- [ ] Assign roles: host (introduces and moderates), check-in, timekeeper, photographer (only with the speaker's and audience's consent for anything that will be posted).
- [ ] Prepare five audience questions in case the room is quiet.

### T-1 day

- [ ] Test the projector, audio, and the Bevy live stream if the talk is being streamed.
- [ ] Print a small sign for the door and a thank-you card.

## Day-of run sheet

| Time (from start) | What | Who |
|---|---|---|
| -0:45 | Room open, tech test with the speaker's laptop, water on the table | Event lead, tech |
| -0:30 | Check-in open on Bevy. Greet at the door | Check-in |
| 0:00 | Welcome. Independence line: the chapter is an independent group and this talk is not a Google statement. Acknowledge ASRCC if funded. Introduce the speaker | Host |
| 0:05 | Talk | Speaker |
| 0:35 | Q&A. Host asks the first question if nobody does | Host |
| 0:50 | Thank the speaker, hand over the card, one ask for the audience (next event on Bevy, Discord) | Host |
| 0:55 | Group photo if everyone agrees. Check-in sweep | Check-in |
| 1:00 | Walk the speaker out. Room reset | Event lead |

## After

- [ ] Thank-you email to the speaker within 48 hours; include the attendance count and any recording link.
- [ ] Reimbursements: submit receipts per [reimbursements.md](../02-operations/reimbursements.md). Log actuals against the budget lines in the event folder.
- [ ] Export registered vs checked-in from Bevy. Record counts in the event folder and the semester budget if ASRCC funded it.
- [ ] Post the recording link (if the speaker agreed) in Discord.
- [ ] Fill in [templates/event-retro.md](../../templates/event-retro.md) within a week. Note the real attendance against the 50+ target so next year's funding request is grounded.
